## 复现 HTTP 测试

先在测试环境安装网站仓库自己的依赖和 pytest。以下夹具只绑定本机回环地址，明确使用临时合成数据，不要指向生产目录：

```powershell
python mobile-app/test/support/phone_contract_fixture.py `
  --backend-root <网站仓库绝对路径> `
  --ffmpeg-dir <包含ffmpeg.exe和ffprobe.exe的目录> `
  --ready-file <本机临时ready.json> --port 18031
```

另开终端，读取该 ready.json 的 video_path，进入 mobile-app 后运行：

```powershell
flutter test --no-pub --dart-define=B_CONTRACT_URL=http://127.0.0.1:18031 --dart-define=B_CONTRACT_VIDEO=<临时合成视频绝对路径>
```

夹具和测试代码内只有固定的测试令牌。它不读取/写入真实模型密钥、不连接摄像头、不调用付费模型；服务端来源收集器仅在该隔离 app 实例中替换，使用真实 A 的告警持久化、HTTP 路由、上传与任务实现。停止测试服务后无需让它继续运行。
