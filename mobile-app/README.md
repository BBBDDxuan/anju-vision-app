# 原版：安居视界 Android v1.2.1

在 v1.2.0 全部能力上恢复第一版首页视觉和“首页｜设备｜消息｜我的”导航。三个主功能“成员监护｜家中风险｜物品寻找”移入首页卡片，点开进入详情页。

## 本版调整

- 保留第一版家庭插画、绿色概览卡片、问候语、重点事件和设备卡片。数据来自真实服务；不预置模拟事件。
- 首页和设备页均可打开实时摄像头、上传 MP4 和录像库。
- 三个详情页继续使用原有成员档案与绑定、人物/环境事件分区、物品搜索与历史、证据回看功能。
- 消息恢复独立底栏入口，保留搜索、状态、类型和日期筛选，显示待处理徽标。
- 我的保留联系人、通知权限/渠道、双服务连接和开源许可；“使用帮助”提供完整离线手册与搜索。
- 手册共 15 章，与交付 HTML/Markdown 内容同源，覆盖全部功能、模型与费用、连接方式和限制。

## 沿用 v1.2.0 的视频功能

原生 VideoLAN RTSP H.264/H.265 播放、局域网设备参数安全存储、已有 MP4 分片上传/取消、录像库/删除、安全分析/物体追踪、任务进度/暂停/继续、危险告警、分类事件、时间线、原片定位、证据与问答、原网页完整工作台全部保留。照片分析继续移除。

本次仅修改 App；没有修改 web-ui 或后端。实时预览直连摄像头；连续实时 AI 仍须在电脑现有网页启动，原后端的摄像头控制接口本机限制继续生效。

## 连接与模型

手机、电脑、摄像头需网络互通。“我的 → 连接服务”配置录像后端根地址，通常为 `http://电脑局域网IP:8000`；模拟器访问本机用 `http://10.0.2.2:8000`。可选安全后端另填地址与用户令牌。端口、白名单、认证和防火墙沿用原项目配置。

危险识别、物体追踪和模型问答在电脑后端运行，安装 App 不会自动安装模型。服务端模型、调用量与 token 费用由原配置和提供商决定。问答增强默认关闭；安全链路仍可能使用后端复核模型。本地包未启用 Firebase，录像后台推送尚未实现。
